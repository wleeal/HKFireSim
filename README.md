# 연구 목표: 3D/2D 딥러닝 기반 화재 확산 시뮬레이션 구현 및 최적화

## 1. 구현 목표
- 열전달(전도·대류·복사) 및 연료 소모 방정식을 반영한 딥러닝 기반 화재 확산 모델을 `src/fire_spread_sim.py`에 구현한다.
- 격자(Voxel/Grid) 기반 환경에서 시간에 따른 온도장(Temperature field)과 연기/연료 밀도 변화를 예측해야 한다.

## 2. 개선 우선순위
1. **물리적 정합성:** 에너지 보존 법칙 및 비음수 조건(온도·연료 밀도 >= 0) 유지, 수치적 발산(NaN/Inf) 방지.
2. **연산 속도:** PyTorch 텐서 연산 벡터화를 통해 단일 타임스텝 추론 시간을 최소화할 것.
3. **코드 품질:** 모든 수정 사항은 `pytest tests/test_physics_and_speed.py`를 통과해야 한다.
